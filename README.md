## 📌 Project Overview

DevHire is a modern freelance marketplace platform where users can explore freelance jobs, post jobs, accept tasks, and manage their own job listings. The platform provides a smooth and responsive user experience with secure authentication and dynamic job management features.

---

## 🚀 Features

- 🔐 Firebase Authentication system (Email/Password & Google Login)
- 📝 Users can add, update, and delete their own jobs
- 🎯 Private Routes for protected pages
- 🌙 Dark & Light theme toggle system
- 🔍 Search and category-based job filtering
- 📦 Responsive UI for mobile, tablet, and desktop
- ⚡ Loading spinner while fetching data
- 🚫 Users cannot accept their own posted jobs
- 🔔 Toast notifications for success and error messages
- ❌ Custom 404 Not Found page
